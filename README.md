# 랜덤 조각 액자

칠교처럼 무작위로 나뉜 스테인드글라스 조각을 나무 액자 안에 담은 인터랙티브 웹 페이지입니다.
빌드 도구나 외부 라이브러리 없이 HTML, CSS, 자바스크립트 파일만으로 동작합니다.

## 기능

- **랜덤 조각 액자:** 사각형과 삼각형 조각이 빈틈 없이 채워집니다. "새로 만들기"를 누르면 배치와 7색 팔레트가 새로 정해집니다.
- **후레쉬:** 마우스(또는 터치 이동)가 후레쉬가 되어 빛이 닿은 조각을 더 밝고 선명하게 비춥니다. 빛을 받은 조각에는 무지개 띠가 생깁니다.
- **빛 번짐:** 조각을 클릭하면 이웃한 조각으로 빛이 한 칸씩 번져 나갑니다.
- **조각 들어 올리기:** 조각을 끌면 들어 올려 옮길 수 있고, 놓으면 원래 자리로 돌아갑니다.
- **하루의 시간:** 아침, 낮, 저녁, 밤으로 하늘과 격자, 빛의 색이 바뀝니다. "다음 시간" 버튼으로 바로 넘길 수 있고, 가만히 두면 150초마다 한 바퀴를 돕니다.
- **반응형:** 데스크톱과 휴대폰 모두에서 액자 크기와 안내 문구가 화면에 맞춰집니다.
- **스크롤로 이동:** 휠이나 트랙패드, 또는 휴대폰에서 한 손가락으로 빈 곳을 밀면 작품 전체가 움직입니다.

## 조작법

| 동작 | 데스크톱 | 휴대폰·태블릿 |
| --- | --- | --- |
| 빛 비추기 | 마우스 움직이기 | 손가락 끌기 |
| 빛 번짐 | 조각 클릭 | 조각 탭 |
| 조각 들어 올리기 | 조각을 끌기 | 조각을 끌기 |
| 작품 옮기기 | 빈 곳을 끌기 또는 휠 | 빈 곳을 밀기 |

## 실행 방법

`index.html`을 브라우저로 열면 됩니다.

로컬 서버로 여는 방법은 다음과 같습니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`에 접속합니다.

## 파일 구성

```
.
├── index.html   화면 구조 (캔버스, 안내 문구, 버튼)
├── style.css    HUD 스타일과 반응형 규칙
├── app.js       조각 생성, 빛, 시간대, 입력 처리
└── README.md
```

## 조정하기

- 조각 개수: `makeTiling()`에서 열과 행의 범위(`rnd(5, 8)`)를 바꿉니다.
- 칠교 7색: `makePalette()`에서 채도와 명도 범위를 바꿉니다.
- 하루 한 바퀴 길이: `DAY_LEN`(초)을 바꿉니다.
- 시간대별 색: `SKY` 배열을 수정합니다.
- 후레쉬 반경: `drawFlashlightGlow()`의 `S * 0.5`를 바꿉니다.
